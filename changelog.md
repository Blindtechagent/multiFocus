\# MultiFocus 1.0.0



Initial release of MultiFocus - Multiple Cursors \& Focus Manager for NVDA.



\### Features



\- Create and save multiple cursors at different locations.

\- Toggle quickly between the two most recent cursor positions.

\- Cycle forward and backward through saved cursors.

\- Open a Cursor Manager dialog to review, jump to, and delete cursors.

\- Peek at lines around another cursor without moving the active focus.

\- Automatically switch to the appropriate application window when jumping to a cursor.

\- Assign and jump directly to Cursor 1 through Cursor 9.

\- Audio feedback and quick help for essential shortcuts.

\- All gestures can be customized through NVDA's Input Gestures settings.
